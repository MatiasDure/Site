## Overview

A classic roguelike dungeon crawler with procedurally generated levels, turn-based combat, and a permadeath system. Every run is unique thanks to randomized map layouts, enemy spawns, and loot tables.

## Tech Stack

- **Engine**: Unity 2022 LTS
- **Language**: C#
- **Art**: Aseprite (pixel art)

## Key Features

- Procedurally generated dungeons using BSP tree algorithm
- Turn-based tactical combat system
- Permadeath with unlockable starter classes
- 50+ item types with randomized stats
