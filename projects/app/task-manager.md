## Overview

A cross-platform mobile task management app for iOS and Android. It uses local SQLite for offline-first data storage with background sync when connectivity is restored.

## Tech Stack

- **Framework**: React Native (Expo)
- **Language**: TypeScript
- **Storage**: SQLite (expo-sqlite)
- **Notifications**: Expo Notifications

## Key Features

- Offline-first architecture with local SQLite storage
- Background sync on reconnect
- Push notifications for due reminders
- Dark/light theme with system preference detection
